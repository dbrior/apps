# Apps by Daniel Brior

Public support, privacy, and terms pages for my apps, served with GitHub Pages at
**https://dbrior.github.io/apps/**.

| App | Support | Privacy | Terms |
|---|---|---|---|
| Up Already | [/up-already/](https://dbrior.github.io/apps/up-already/) | [/up-already/privacy/](https://dbrior.github.io/apps/up-already/privacy/) | [/up-already/terms/](https://dbrior.github.io/apps/up-already/terms/) |

## Adding an app

1. Copy `up-already/` to a new folder named after the app (lowercase, hyphenated).
2. Rewrite the three pages for that app. Keep the privacy policy accurate to what the app actually collects.
3. Add the app to `index.html` and to the table above.

Plain HTML and one shared `style.css`; there's no build step. `.nojekyll` tells GitHub Pages to serve the files as-is.
